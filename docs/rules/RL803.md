# RL803 `reflow`

Content must fit a 320 CSS pixel wide screen without scrolling sideways.

## WCAG

- [1.4.10 Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) (level AA)

## Why it matters

People who zoom to 400 % see the page as if it were 320 CSS pixels wide. If content does not reflow to that width they must scroll sideways for every line, and lose their place.

## What ramplint reports

This rule needs a rendered page: it runs in the browser scan
(`ramplint http://localhost:8000/` or `ramplint --runserver`) and is skipped
when ramplint lints templates.

- Pages that scroll horizontally at a 320 CSS px wide viewport. The problem names the element that sticks out the most, e.g. `#banner ends at 648 px`.

## Examples

Problems:

```html
<div style="width: 640px">A fixed-width banner</div>
```

Fixed:

```html
<div style="max-width: 640px">A banner that shrinks</div>
```

## Not reported

- Content that needs two dimensions to make sense: tables, `<pre>` and code, maps, diagrams, video, `<canvas>` (the WCAG exception).
- Content that scrolls inside its own box (`overflow-x: auto`).

## Suppressing

Put an HTML comment (it stays in the rendered page) on the line with the
element or the line above it:

```html
<!-- ramplint: ignore RL803 -->
```

or disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL803"]
```
