# RL302 `empty-heading`

Headings must have text content.

## WCAG

- [2.4.6 Headings and Labels](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html) (level AA)

## Why it matters

An empty heading is announced as "heading level 2" with nothing after it, which is confusing in the headings list. Icon-only headings have the same problem.

## What ramplint reports

- `<h1>`–`<h6>` without text, image `alt` text, `aria-label` or `aria-labelledby`.

## Examples

Problems:

```django
{# ✗ #} <h2 class="section-title"></h2>
{# ✗ #} <h2><i class="icon-star"></i></h2>
```

Fixed:

```django
{# ✓ #} <h2>{% trans "Favourites" %}</h2>
{# ✓ #} <h1>{% block title %}{% endblock %}</h1>
```

## Not reported

- Text that only exists at runtime: `{{ title }}`, `{% trans %}`, `{% block %}`, `{% include %}`.
- Headings hidden with `aria-hidden="true"`.

## Suppressing

```django
{# ramplint: ignore RL302 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL302 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL302"]
```
