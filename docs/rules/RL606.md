# RL606 `obsolete-elements`

<marquee> and <blink> must not be used.

## WCAG

- [2.2.2 Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) (level A)

## Why it matters

`<marquee>` scrolls and `<blink>` flashes content with no way to pause it. Moving text is hard or impossible to read for people with low vision, dyslexia or attention disorders, and it pulls focus away from the rest of the page. Both elements are obsolete in HTML.

## What ramplint reports

- `<marquee>` and `<blink>` elements.

## Examples

Problems:

```django
{# ✗ #} <marquee>{% trans "Free shipping on all orders!" %}</marquee>
{# ✗ #} <blink>{% trans "New" %}</blink>
```

Fixed:

```django
{# ✓ #} <p class="banner">{% trans "Free shipping on all orders!" %}</p>
{# ✓ #} <span class="badge">{% trans "New" %}</span>
```

If the content must move, use a CSS animation that stops for `prefers-reduced-motion` and add a visible pause button.

## Not reported

- Classes and roles with the same name (`class="marquee"`, `role="marquee"`).

## Suppressing

```django
{# ramplint: ignore RL606 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL606 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL606"]
```
