# RL601 `html-lang`

The <html> element must declare the page language.

## WCAG

- [3.1.1 Language of Page](https://www.w3.org/WAI/WCAG22/Understanding/language-of-page.html) (level A)

## Why it matters

Screen readers choose a voice and pronunciation from `lang`. Without it a Romanian page may be read with English rules, and browsers cannot offer translation reliably.

## What ramplint reports

- `<html>` without a non-empty `lang` attribute.

## Examples

Problems:

```django
{# ✗ #} <html>
```

Fixed:

```django
{# ✓ #} <html lang="{{ LANGUAGE_CODE }}">
{# ✓ #} <html lang="en">
```

## Not reported

- Templates without an `<html>` element (partials and child templates).

## Suppressing

```django
{# ramplint: ignore RL601 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL601 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL601"]
```
