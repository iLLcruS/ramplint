# RL705 `aria-hidden-focus`

Content with aria-hidden="true" must not be focusable.

## WCAG

- [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html) (level A)

## Why it matters

`aria-hidden="true"` removes content from screen readers, but not from the keyboard. Users can tab to a link or button their screen reader cannot announce, and hear nothing.

## What ramplint reports

- Links with `href`, buttons, form controls, `<iframe>`, `<summary>`, `contenteditable` elements and elements with `tabindex` of 0 or more inside `aria-hidden="true"`.
- `aria-hidden="true"` on a focusable element itself.

## Examples

Problems:

```django
{# ✗ #} <div class="carousel-clone" aria-hidden="true"><a href="{{ slide.url }}">{{ slide.title }}</a></div>
{# ✗ #} <button aria-hidden="true"><i class="icon-x"></i></button>
```

Fixed:

```django
{# ✓ #} <div class="carousel-clone" aria-hidden="true"><a href="{{ slide.url }}" tabindex="-1">{{ slide.title }}</a></div>
{# ✓ #} <span aria-hidden="true"><i class="icon-star"></i></span>
```

## Not reported

- Elements with `tabindex="-1"` or `disabled`.
- Elements with dynamic `tabindex` or dynamic attributes.
- Content of `<template>`.

## Suppressing

```django
{# ramplint: ignore RL705 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL705 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL705"]
```
