# RL304 `list-structure`

Lists may only contain <li>, and <li> must be inside a list.

## WCAG

- [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html) (level A)

## Why it matters

Screen readers announce a list as "list, 5 items" and let users jump over it or move from item to item. That only works when the items are `<li>` elements directly inside `<ul>` or `<ol>`. A `<div>` or `<a>` placed straight in a `<ul>` is not counted as an item, and an `<li>` outside a list is announced as plain text.

## What ramplint reports

- Direct children of `<ul>` / `<ol>` other than `<li>`, `<script>` and `<template>`.
- `<li>` that is not inside `<ul>`, `<ol>` or `<menu>` (or an element with `role="list"`).

## Examples

Problems:

```django
{# ✗ #} <ul class="menu"><a href="{% url 'home' %}">Home</a><a href="{% url 'shop' %}">Shop</a></ul>
{# ✗ #} <ul>{% for tag in tags %}<div class="tag">{{ tag }}</div>{% endfor %}</ul>
{# ✗ #} <div class="steps"><li>{% trans "Cart" %}</li><li>{% trans "Payment" %}</li></div>
```

Fixed:

```django
{# ✓ #} <ul class="menu"><li><a href="{% url 'home' %}">Home</a></li><li><a href="{% url 'shop' %}">Shop</a></li></ul>
{# ✓ #} <ul>{% for tag in tags %}<li class="tag">{{ tag }}</li>{% endfor %}</ul>
{# ✓ #} <ol class="steps"><li>{% trans "Cart" %}</li><li>{% trans "Payment" %}</li></ol>
```

## Not reported

- Lists whose items come from `{% include %}`, `{% block %}` or a variable.
- `<li>` at the top level of a partial template, for example `{% for %}<li>…</li>{% endfor %}` in `menu_items.html`: it is included into a list elsewhere. Full-page templates (with an `<html>` element) are still checked.
- Lists with a different role (`role="tablist"`, `role="none"`, ...), children with `role="listitem"`, and elements with dynamic attributes or a dynamic `role`.
- Content of `<template>`.
- An `<li>` inside a wrong wrapper (`<ul><div><li>`): the wrapper is reported instead.

## Suppressing

```django
{# ramplint: ignore RL304 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL304 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL304"]
```
