# RL603 `document-title`

Pages must have a non-empty <title>.

## WCAG

- [2.4.2 Page Titled](https://www.w3.org/WAI/WCAG22/Understanding/page-titled.html) (level A)

## Why it matters

The title is the first thing a screen reader announces when a page opens, and the only label users see in tabs, bookmarks and history. Without it, every page of the site sounds the same.

## What ramplint reports

- A full-page template (one with an `<html>` element) without a `<title>`.
- An empty `<title>`.

A `<title>` inside `<svg>` names the graphic, not the page, so it does not count.

## Examples

Problems:

```django
{# ✗ #} <html lang="en"><head><meta charset="utf-8"></head><body><main>{{ content }}</main></body></html>
{# ✗ #} <html lang="en"><head><title></title></head><body><main>{{ content }}</main></body></html>
```

Fixed:

```django
{# ✓ #} <html lang="en"><head><title>{% block title %}Shoply{% endblock %}</title></head><body><main>{{ content }}</main></body></html>
{# ✓ #} <html lang="en"><head><title>{{ page_title }} | Shoply</title></head><body><main>{{ content }}</main></body></html>
```

Child templates fill the block: `{% block title %}{% trans "Orders" %} | Shoply{% endblock %}`.

## Not reported

- Titles from variables, `{% block %}`, `{% trans %}` and other template tags.
- Pages whose `<head>` contains a `{% block %}`, `{% include %}` or custom tag that may render the `<title>`.
- Partials and child templates (no `<html>`): the parent template owns the title.

## Suppressing

```django
{# ramplint: ignore RL603 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL603 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL603"]
```
