# RL901 `page-title-unique`

Different pages must have different titles.

## WCAG

- [2.4.2 Page Titled](https://www.w3.org/WAI/WCAG22/Understanding/page-titled.html) (level A)

## Why it matters

The title is the first thing a screen reader announces and the name of the tab and the bookmark. When different pages share a title, users cannot tell them apart.

## What ramplint reports

This rule needs a rendered page: it runs in the browser scan
(`ramplint http://localhost:8000/` or `ramplint --runserver`) and is skipped
when ramplint lints templates.

- Pages of different URL patterns (e.g. `/` and `/shop/`) with the same `<title>`. The problem lists every page with that title.

## Examples

Problems:

```html
<!-- / -->      <title>Shoply</title>
<!-- /shop/ --> <title>Shoply</title>
```

Fixed:

```html
<!-- / -->      <title>Shoply</title>
<!-- /shop/ --> <title>Shop | Shoply</title>
```

## Not reported

- Pages of the same URL pattern, such as `/list/?page=1` and `/list/?page=2`.

## Suppressing

Put an HTML comment (it stays in the rendered page) on the line with the
element or the line above it:

```html
<!-- ramplint: ignore RL901 -->
```

or disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL901"]
```
