# RL507 `focusable-role`

Elements with an interactive role must be focusable.

## WCAG

- [2.1.1 Keyboard](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html) (level A)
- [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html) (level A)

## Why it matters

`role="button"` or `role="switch"` tells screen readers that an element is a control, but it does not make the element reachable with the Tab key. Keyboard users hear about a control they can never operate. Native elements (`<button>`, `<input type="checkbox">`) are focusable and handle Space and Enter for free.

## What ramplint reports

- Elements with the role `button`, `link`, `checkbox`, `switch`, `radio`, `tab`, `menuitem`, `menuitemcheckbox`, `menuitemradio`, `slider`, `spinbutton`, `combobox`, `textbox` or `searchbox` that are not natively focusable and have no `tabindex`.

## Examples

Problems:

```django
{# ✗ #} <div role="switch" aria-checked="false">{% trans "Dark mode" %}</div>
{# ✗ #} <span class="link" role="link" onclick="go('{{ url }}')">{% trans "Details" %}</span>
```

Fixed:

```django
{# ✓ #} <div role="switch" aria-checked="false" tabindex="0">{% trans "Dark mode" %}</div>
{# ✓ #} <a href="{{ url }}">{% trans "Details" %}</a>
{# ✓ #} <div role="tablist"><span role="tab" tabindex="0" aria-selected="true">A</span><span role="tab" tabindex="-1" aria-selected="false">B</span></div>
```

A focusable custom control also needs key handlers (Space and Enter for buttons, arrow keys for tabs and sliders). A native element is almost always simpler.

## Not reported

- Natively focusable elements: `<button>`, `<a href>`, form controls, `<summary>`, `contenteditable`.
- Any `tabindex`, including `tabindex="-1"` (roving focus in tab lists, menus and toolbars).
- `aria-disabled="true"`, `disabled`, content hidden with `aria-hidden="true"`, and elements inside a container with `aria-activedescendant` (the container keeps the focus).
- `option`, `treeitem` and `gridcell`: their focus is usually managed by the list, tree or grid.
- Dynamic attributes or a dynamic `role`, and content of `<template>`.

## Suppressing

```django
{# ramplint: ignore RL507 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL507 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL507"]
```
