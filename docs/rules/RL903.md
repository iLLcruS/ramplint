# RL903 `consistent-identification`

Controls that do the same thing on different pages must have the same name.

## WCAG

- [3.2.4 Consistent Identification](https://www.w3.org/WAI/WCAG22/Understanding/consistent-identification.html) (level AA)

## Why it matters

A control that does the same thing on every page should be called the same everywhere. If the logo link is "Shoply" on one page and "Home page" on another, screen reader users wonder whether it is a different link.

## What ramplint reports

This rule needs a rendered page: it runs in the browser scan
(`ramplint http://localhost:8000/` or `ramplint --runserver`) and is skipped
when ramplint lints templates.

- Links to the same URL, in the same landmark (header, navigation, footer...), with different accessible names on different pages.
- Buttons with the same icon with different names on different pages.

## Examples

Problems:

```html
<!-- / -->       <header><a href="/" aria-label="Shoply"><img src="/logo.svg" alt=""></a></header>
<!-- /about/ --> <header><a href="/" aria-label="Home page"><img src="/logo.svg" alt=""></a></header>
```

Fixed:

```html
<!-- / -->       <header><a href="/" aria-label="Shoply"><img src="/logo.svg" alt=""></a></header>
<!-- /about/ --> <header><a href="/" aria-label="Shoply"><img src="/logo.svg" alt=""></a></header>
```

## Not reported

- The same URL linked from different places with different names (a "Home" link in the navigation and a logo in the header).
- Differences in case and spaces.

## Suppressing

Put an HTML comment (it stays in the rendered page) on the line with the
element or the line above it:

```html
<!-- ramplint: ignore RL903 -->
```

or disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL903"]
```
