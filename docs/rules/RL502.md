# RL502 `link-name`

Links must have an accessible name.

## WCAG

- [2.4.4 Link Purpose (In Context)](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html) (level A)
- [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html) (level A)

## Why it matters

Screen reader users often jump through a list of links. A link with no text is announced as its URL or as "link", which says nothing about where it goes.

## What ramplint reports

- `<a href>` without text, image `alt`, an SVG `<title>`, `aria-label`, `aria-labelledby` or `title`.

## Examples

Problems:

```django
{# ✗ #} <a href="{% url 'cart' %}"><i class="icon-cart"></i></a>
{# ✗ #} <a href="/"><img src="logo.png"></a>
```

Fixed:

```django
{# ✓ #} <a href="{% url 'cart' %}" aria-label="Cart"><i class="icon-cart" aria-hidden="true"></i></a>
{# ✓ #} <a href="/"><img src="logo.png" alt="Shoply home"></a>
```

## Not reported

- `<a>` without `href` (named anchors).
- Content that only exists at runtime.

## Suppressing

```django
{# ramplint: ignore RL502 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL502 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL502"]
```
