# RL203 `empty-table-header`

Table header cells must have text.

## WCAG

- [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html) (level A)

## Why it matters

Screen readers read the header together with every cell in its column or row. An empty `<th>` (for example above a column of "Edit" buttons) leaves users guessing what the cells mean. If the header should not be visible, keep the text and hide it visually.

## What ramplint reports

- `<th>` without text, image alt text, `aria-label`, `aria-labelledby` or `title`. `&nbsp;` and icons without a name do not count as text.

## Examples

Problems:

```django
{# ✗ #} <table><tr><th>{% trans "Order" %}</th><th></th></tr><tr><td>{{ order.number }}</td><td><a href="{{ order.url }}">{% trans "Edit" %}</a></td></tr></table>
{# ✗ #} <table><tr><th>{% trans "Name" %}</th><th><i class="icon-sort"></i></th></tr></table>
```

Fixed:

```django
{# ✓ #} <table><tr><th>{% trans "Order" %}</th><th><span class="visually-hidden">{% trans "Actions" %}</span></th></tr><tr><td>{{ order.number }}</td><td><a href="{{ order.url }}">{% trans "Edit" %}</a></td></tr></table>
{# ✓ #} <table><tr><th>{% trans "Name" %}</th><th aria-label="{% trans 'Sort' %}"><i class="icon-sort"></i></th></tr></table>
```

## Not reported

- Text from variables, `{% trans %}` or `{% include %}`.
- The top-left corner cell of a table that has both column headers and row headers.
- Header cells with `aria-hidden="true"` or dynamic attributes, and cells of layout tables (`role="presentation"` / `role="none"`).

## Suppressing

```django
{# ramplint: ignore RL203 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL203 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL203"]
```
