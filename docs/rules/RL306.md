# RL306 `landmark-one-main`

A page must have exactly one main landmark.

## WCAG

- [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html) (level A)
- [2.4.1 Bypass Blocks](https://www.w3.org/WAI/WCAG22/Understanding/bypass-blocks.html) (level A)

## Why it matters

Screen reader users jump to the main content with a single key, skipping the header and navigation. That needs exactly one `<main>` (or `role="main"`) on the page. With two, the shortcut lands on the wrong one; with none, there is nothing to jump to.

## What ramplint reports

- A second `<main>` / `role="main"` in a template, pointing to the first one. The same element in `{% if %}` / `{% else %}` branches is fine.
- A full-page template (one with an `<html>` element) that has no main landmark and no `{% block %}`, `{% include %}` or custom tag that could render one. Standalone pages such as `500.html` are the usual case.

## Examples

Problems:

```django
{# ✗ #} <main class="content">{% block content %}{% endblock %}</main><main class="sidebar">{% block sidebar %}{% endblock %}</main>
{# ✗ #} <html lang="en"><head><title>Server error</title></head><body><h1>Something went wrong</h1></body></html>
```

Fixed:

```django
{# ✓ #} <main class="content">{% block content %}{% endblock %}</main><aside class="sidebar">{% block sidebar %}{% endblock %}</aside>
{# ✓ #} <div><h1>Something went wrong</h1></div>
```

A full page with its main landmark:

```html
<html lang="en">
<head><title>Server error</title></head>
<body><main><h1>Something went wrong</h1></main></body>
</html>
```

## Not reported

- `<main hidden>`: extra hidden main elements are allowed, for example inactive views of a single-page app.
- Pages without any text, for example a popup that only runs a script and closes itself.
- Partials and child templates (no `<html>`): the main landmark may be in the parent template.
- Full pages whose content comes from `{% block %}`, `{% include %}` or elements with dynamic attributes.
- Content of `<template>`.

## Suppressing

```django
{# ramplint: ignore RL306 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL306 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL306"]
```
