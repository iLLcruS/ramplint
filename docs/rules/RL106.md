# RL106 `media-autoplay`

Media must not play sound automatically.

## WCAG

- [1.4.2 Audio Control](https://www.w3.org/WAI/WCAG22/Understanding/audio-control.html) (level A)

## Why it matters

Screen readers speak through the same speakers. Sound that starts on its own drowns out the screen reader, often before the user can find the control that stops it. It is also startling for everyone else.

## What ramplint reports

- `<video autoplay>` and `<audio autoplay>` without `muted`.

## Examples

Problems:

```django
{# ✗ #} <video autoplay loop src="{% static 'video/promo.mp4' %}"></video>
{# ✗ #} <audio autoplay src="{% static 'audio/jingle.mp3' %}"></audio>
```

Fixed:

```django
{# ✓ #} <video autoplay muted loop playsinline src="{% static 'video/promo.mp4' %}"></video>
{# ✓ #} <audio controls src="{% static 'audio/jingle.mp3' %}"></audio>
```

## Not reported

- `autoplay` from a variable or template tag, and elements with dynamic attributes.
- Content of `<template>`.

WCAG allows sound that stops within 3 seconds; ramplint cannot see how long a file is, so suppress the problem inline if that is the case.

## Suppressing

```django
{# ramplint: ignore RL106 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL106 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL106"]
```
