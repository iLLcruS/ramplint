# RL501 `button-name`

Buttons must have an accessible name.

## WCAG

- [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html) (level A)

## Why it matters

Icon-only buttons are announced as just "button". Users of screen readers and voice control ("click Delete") cannot tell them apart or activate them by name.

## What ramplint reports

- `<button>` and elements with `role="button"` without text, image `alt`, an SVG `<title>`, `aria-label`, `aria-labelledby` or `title`.
- `<input type="button">` without a `value`.

## Examples

Problems:

```django
{# ✗ #} <button><i class="fa fa-trash"></i></button>
{# ✗ #} <div role="button" tabindex="0"><span class="hamburger"></span></div>
```

Fixed:

```django
{# ✓ #} <button aria-label="{% trans 'Delete' %}"><i class="fa fa-trash" aria-hidden="true"></i></button>
{# ✓ #} <button><span class="visually-hidden">Delete</span><i class="fa fa-trash"></i></button>
```

## Not reported

- `<input type="submit">` and `<input type="reset">`: browsers give them a default name.
- Content that only exists at runtime (`{{ label }}`, `{% trans %}`, `{% include %}`).

## Suppressing

```django
{# ramplint: ignore RL501 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL501 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL501"]
```
