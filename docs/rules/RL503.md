# RL503 `no-positive-tabindex`

tabindex must not be greater than 0.

## WCAG

- [2.4.3 Focus Order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html) (level A)

## Why it matters

Elements with a positive `tabindex` are focused before everything else on the page, in numeric order. Keyboard users jump around unpredictably, and every new element has to be squeezed into the numbering.

## What ramplint reports

- `tabindex` with a value greater than 0.

## Examples

Problems:

```django
{# ✗ #} <a href="{% url 'search' %}" tabindex="1">Search</a>
```

Fixed:

```django
{# ✓ #} <div role="button" tabindex="0">Menu</div>
{# ✓ #} <div id="dialog" tabindex="-1">…</div>
```

## Not reported

- `tabindex="0"` (focusable in document order) and negative values (focusable from script only).
- Values from variables or built with template tags.

## Suppressing

```django
{# ramplint: ignore RL503 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL503 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL503"]
```
