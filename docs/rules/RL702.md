# RL702 `aria-valid-attr`

aria-* attributes must exist in WAI-ARIA.

## WCAG

- [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html) (level A)

## Why it matters

Misspelled ARIA attributes are ignored without any warning. `aria-lable="Close"` leaves an icon button without a name, and `aria-labeledby` (one l) never links the label.

## What ramplint reports

- `aria-*` attributes that are not defined by WAI-ARIA, with a "did you mean" suggestion.

## Examples

Problems:

```django
{# ✗ #} <button aria-lable="Close"><i class="icon-x"></i></button>
{# ✗ #} <section aria-labeledby="title">…</section>
```

Fixed:

```django
{# ✓ #} <button aria-label="Close"><i class="icon-x" aria-hidden="true"></i></button>
{# ✓ #} <section aria-labelledby="title"><h2 id="title">Orders</h2></section>
```

## Not reported

- Attributes rendered dynamically (`{{ attrs }}`).

## Suppressing

```django
{# ramplint: ignore RL702 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL702 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL702"]
```
