# RL902 `consistent-navigation`

Navigation repeated on several pages must keep its links in the same order.

## WCAG

- [3.2.3 Consistent Navigation](https://www.w3.org/WAI/WCAG22/Understanding/consistent-navigation.html) (level AA)

## Why it matters

People who use a screen reader or screen magnification learn where things are. If the main navigation lists its links in a different order on some pages, they lose their way.

## What ramplint reports

This rule needs a rendered page: it runs in the browser scan
(`ramplint http://localhost:8000/` or `ramplint --runserver`) and is skipped
when ramplint lints templates.

- A `<nav>` (identified by its `aria-label`, or by its position) whose links shared with the same navigation on other pages come in a different order. Links that appear only on some pages are allowed.

## Examples

Problems:

```html
<!-- / -->       <nav aria-label="Main"><a href="/">Home</a><a href="/shop/">Shop</a><a href="/about/">About</a></nav>
<!-- /about/ --> <nav aria-label="Main"><a href="/">Home</a><a href="/about/">About</a><a href="/shop/">Shop</a></nav>
```

Fixed:

```html
<!-- / -->       <nav aria-label="Main"><a href="/">Home</a><a href="/shop/">Shop</a><a href="/about/">About</a></nav>
<!-- /about/ --> <nav aria-label="Main"><a href="/">Home</a><a href="/shop/">Shop</a><a href="/about/">About</a></nav>
```

## Not reported

- Different navigations (different labels) with different links.
- Extra links added on some pages.

## Suppressing

Put an HTML comment (it stays in the rendered page) on the line with the
element or the line above it:

```html
<!-- ramplint: ignore RL902 -->
```

or disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL902"]
```
