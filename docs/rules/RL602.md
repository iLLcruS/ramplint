# RL602 `viewport-zoom`

The viewport meta tag must not disable zooming.

## WCAG

- [1.4.4 Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html) (level AA)

## Why it matters

People with low vision pinch to zoom. `user-scalable=no` or a small `maximum-scale` blocks that on many mobile browsers. WCAG requires text to be resizable up to 200%.

## What ramplint reports

- `<meta name="viewport">` with `user-scalable=no` (or `0`, `false`).
- `maximum-scale` below 2.

## Examples

Problems:

```django
{# ✗ #} <meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no">
{# ✗ #} <meta name="viewport" content="width=device-width, maximum-scale=1">
```

Fixed:

```django
{# ✓ #} <meta name="viewport" content="width=device-width, initial-scale=1">
```

## Not reported

- Values from variables, and invalid values that browsers ignore (`maximum-scale=0`).

## Suppressing

```django
{# ramplint: ignore RL602 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL602 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL602"]
```
