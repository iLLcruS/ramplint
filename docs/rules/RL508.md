# RL508 `label-in-name`

An aria-label must contain the text shown on the control.

## WCAG

- [2.5.3 Label in Name](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html) (level A)

## Why it matters

`aria-label` replaces the visible text as the control's name. Voice control users say what they see ("click Helpful"); if the name is "Mark this review as useful", the command does nothing. Screen reader users who can see the page hear something different from what is on screen.

## What ramplint reports

- Links, buttons, `<input type="submit|button|reset">` and elements with a widget role (`button`, `link`, `tab`, `menuitem`, `checkbox`, `switch`, ...) whose `aria-label` does not contain their visible text (case and spaces are ignored).

## Examples

Problems:

```django
{# ✗ #} <button type="button" aria-label="Mark this review as useful">Helpful</button>
{# ✗ #} <a href="{% url 'orders' %}" aria-label="Purchase history">My orders</a>
```

Fixed:

```django
{# ✓ #} <button type="button" aria-label="Helpful review">Helpful</button>
{# ✓ #} <a href="{% url 'orders' %}">My orders</a>
```

## Not reported

- Visible text that is a symbol or a single character (`×`, `X`, `→`): an `aria-label="Close"` on it is fine.
- Text or `aria-label` built by the template (`{{ }}`, `{% trans %}`).
- `aria-labelledby` (ramplint does not resolve the referenced text).

## Suppressing

```django
{# ramplint: ignore RL508 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL508 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL508"]
```
