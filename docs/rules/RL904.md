# RL904 `bypass-blocks`

Pages with repeated navigation must offer a way to skip it.

## WCAG

- [2.4.1 Bypass Blocks](https://www.w3.org/WAI/WCAG22/Understanding/bypass-blocks.html) (level A)

## Why it matters

Keyboard and screen reader users must move past the header and navigation on every page before they reach the content. A skip link or a `<main>` landmark lets them jump straight to it.

## What ramplint reports

This rule needs a rendered page: it runs in the browser scan
(`ramplint http://localhost:8000/` or `ramplint --runserver`) and is skipped
when ramplint lints templates.

- Pages that repeat the same block of three or more links before the content, and have neither a `<main>` landmark nor a skip link to the content.

## Examples

Problems:

```html
<nav><a href="/">Home</a><a href="/shop/">Shop</a><a href="/about/">About</a></nav>
<div class="content">...</div>
```

Fixed:

```html
<a href="#content">Skip to content</a>
<nav><a href="/">Home</a><a href="/shop/">Shop</a><a href="/about/">About</a></nav>
<main id="content">...</main>
```

## Not reported

- Navigation seen on one page only (it is not repeated).
- Pages with a `<main>` landmark: screen readers can jump to it.

## Suppressing

Put an HTML comment (it stays in the rendered page) on the line with the
element or the line above it:

```html
<!-- ramplint: ignore RL904 -->
```

or disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL904"]
```
