# RL403 `label-for-target`

<label for> must point to an element id in the template.

## WCAG

- [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html) (level A)
- [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html) (level A)

## Why it matters

`<label for="email">` names the element with `id="email"`. If no element has that id (a typo, or an `id` that was renamed or never added), the field has no name for screen readers and clicking the label does nothing. A common case is `for` matching the field's `name` instead of its `id`.

## What ramplint reports

- `<label for>` whose value is empty or does not match any `id` in the template. When a field has a matching `name` but no `id`, or a similar `id` exists, the message says so.

## Examples

Problems:

```django
{# ✗ #} <label for="email">{% trans "Email" %}</label> <input type="email" name="email">
{# ✗ #} <label for="phone-number">{% trans "Phone" %}</label> <input type="tel" id="phone_number" name="phone">
```

Fixed:

```django
{# ✓ #} <label for="email">{% trans "Email" %}</label> <input type="email" id="email" name="email">
{# ✓ #} <label for="phone_number">{% trans "Phone" %}</label> <input type="tel" id="phone_number" name="phone">
{# ✓ #} <label for="{{ form.city.id_for_label }}">{{ form.city.label }}</label> {{ form.city }}
```

## Not reported

- `for` values from variables, such as `{{ field.id_for_label }}`.
- Templates where the target may be rendered somewhere ramplint cannot see: `{% include %}`, `{% block %}`, custom tags such as `{% render_field %}`, rendered form fields (`{{ form.email }}`, `{{ field }}`, `{{ form.as_p }}`, `|as_crispy_field`) and elements with a dynamic `id` or dynamic attributes.
- Labels inside `<template>`.

## Suppressing

```django
{# ramplint: ignore RL403 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL403 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL403"]
```
