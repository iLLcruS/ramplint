# RL505 `nested-interactive`

Interactive elements must not contain other interactive elements.

## WCAG

- [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html) (level A)

## Why it matters

A `<button>` inside a link, or a link inside a button, is invalid HTML. Browsers and screen readers handle it differently: the inner control is often merged into the outer one, announced twice, or cannot be reached with the keyboard at all. A typical case is a product card wrapped in `<a>` with an "Add to cart" button inside.

## What ramplint reports

Inside `<a href>` or `<button>`:

- `<a href>`, `<button>`, `<select>`, `<textarea>`, `<input>` (except `type="hidden"`), `<details>` and `<summary>`.
- Elements with an interactive role (`button`, `link`, `checkbox`, `switch`, `tab`, `menuitem`, ...).
- Elements with `tabindex` of 0 or more.

## Examples

Problems:

```django
{# ✗ #} <a href="{{ product.get_absolute_url }}" class="card"><h3>{{ product.name }}</h3><button type="button">{% trans "Add to cart" %}</button></a>
{# ✗ #} <button type="button"><a href="{% url 'help' %}">{% trans "Help" %}</a></button>
{# ✗ #} <a href="{{ post.url }}"><span role="button" tabindex="0">{% trans "Like" %}</span></a>
```

Fixed:

```django
{# ✓ #} <div class="card"><h3><a href="{{ product.get_absolute_url }}">{{ product.name }}</a></h3><button type="button">{% trans "Add to cart" %}</button></div>
{# ✓ #} <a href="{% url 'help' %}" class="button">{% trans "Help" %}</a>
{# ✓ #} <a href="{{ post.url }}">{{ post.title }}</a> <button type="button">{% trans "Like" %}</button>
```

To keep the whole card clickable, stretch the link over the card with CSS (a `::after` pseudo-element) instead of wrapping the card in it.

## Not reported

- `<a>` without `href` is not interactive, so it may contain controls.
- Elements with `tabindex="-1"`, a dynamic `tabindex` or dynamic attributes.
- Content rendered by `{% include %}` or a variable.
- Content of `<template>`.

## Suppressing

```django
{# ramplint: ignore RL505 #}
```

on the line with the problem or the line above it, or for the whole file:

```django
{# ramplint: ignore-file RL505 #}
```

You can also disable the rule in `pyproject.toml`:

```toml
[tool.ramplint]
ignore = ["RL505"]
```
